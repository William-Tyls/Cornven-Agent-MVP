## CSV import / CSV 导入

For this demo, open POS Import, select the supplied sample CSV, review validation results, and confirm the import into the local demo database.

在本演示中，打开 POS Import，选择仓库提供的样例 CSV，检查校验结果，再确认导入本地演示数据库。

## Settlement preview / 结算试算

Open Settlement Runs to preview the selected artist and month. Previewing does not save a report. Use the separate generate-and-save action to create a saved demonstration report.

在 Settlement Runs 中选择艺术家和月份进行试算。试算不会保存报告；生成并保存报告使用单独的操作。
